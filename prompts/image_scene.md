# 構思聯想圖場景

你的任務：為一張記憶卡片想出一個**視覺場景**，讓學習者看到圖就想起這張卡的內容。

輸入是一張卡的條目、釋義與例句。輸出**只有一行**：英文的場景描述。
不要任何說明、引號、編號、標題或前後綴文字。

---

## 你要產出的是「語義」，不是「成品 prompt」

這一行會由後續步驟依當前的文生圖模型改寫成該模型要的語法。
所以你**只負責畫面內容**，不負責風格。

**絕對不要**輸出下列任何東西——它們屬於後續步驟，由你寫進來只會被重複加一次：

- 風格詞：`cinematic lighting`、`muted color palette`、`soft shadows`、`atmospheric`
- 品質詞：`masterpiece`、`best quality`、`absurdres`、`highly detailed`
- 模型觸發詞：`Anime.`、任何 LoRA 的觸發字
- 否定敘述：`no text`、`no letters`、`no watermark`
- 畫幅、鏡頭、解析度指令：`16:9`、`wide shot`、`4k`

## 輸出格式

- 全部英文小寫，以半形逗號分隔片語，**不使用句號**。
- 一到兩個子句的場景描述，之後可接一個簡短的氛圍片語
  （例：`quiet library mood`、`clinical precision mood`、`motion blur`）。
- 長度約 8 到 30 個英文單字。太短畫不出東西，太長會讓模型顧此失彼。

範例輸出：

```
a tiger standing among a family of housecats, the size difference making it obvious which one does not belong, taxonomy mood
```

---

## 場景怎麼想

判準只有一個：**看到圖能不能想起這張卡的內容。** 這是記憶錨點，不是插圖。

具體場景才記得住，抽象色塊與幾何圖形無法對應到語義。

### 抽象條目的轉換方式

抽象條目最容易產出無意義的圖。轉法：

| 條目性質 | 轉法 | 例 |
|----------|------|-----|
| 抽象關係 | 畫出關係的具體實例 | 「屬於」→ 老虎站在貓科動物之中 |
| 程度／數量 | 畫出對比 | 「増大」→ 同一容器前後水位落差 |
| 動作 | 畫出正在執行該動作的人 | 「測量」→ 檢測員拿儀器量身體數值 |
| 情態副詞 | 畫出符合該情態的動作瞬間 | 「そうっと」→ 有人踮腳輕推一扇門 |
| 邏輯連接 | 畫出兩個場景的因果對照 | 「それでも」→ 大雨中仍撐傘前行的人 |

畫不出來時，寧可畫一個**與該條目典型例句對應的場景**，也不要退回抽象符號。

## 避開會帶出文字的道具

圖像模型看到「螢幕、書封、日曆、招牌、圖表、文件」這類道具，就會自己在上面寫字。
圖上的文字多半是亂碼，而且會讓使用者變成「讀字」而不是「回憶」。

**目標是把出現率壓低，不是保證零出現。** 擴散模型有時會憑空加上場景沒要求的
道具再往上寫字，那不是你能控制的；你能控制的是**不要主動要求這些東西**，
而這一件就足以讓出現率明顯下降。做到這一條就夠了，不必為此把場景扭曲成
畫不出來的東西。

| 不要用 | 改用 |
|--------|------|
| screen、monitor、phone display、laptop screen | 人物專注的表情與手勢、畫面外的光源 |
| book cover、open book、magazine、newspaper、notebook | 闔上的書堆、翻頁的手、攤開的空白版面 |
| calendar、clock、watch face | 窗外的季節變化、光線角度、拉長的影子 |
| sign、signboard、poster、banner、label、nameplate | 建築物本身的形狀、箭頭形的路徑 |
| chart、graph、diagram、whiteboard、blackboard | 實物的大小對照、堆疊高度的差異 |
| document、form、ticket、receipt、certificate | 空白紙張、資料夾、被鎮紙壓住的紙 |
| symbol、logo、card、badge、stamp、envelope、map、menu | 該概念的實物本身、人的動作、空間的形狀 |

**要表達「資訊」時，畫「人對這個資訊的反應」或「該概念的實物對照」**，
兩者都不需要一個字。氛圍片語也一樣——不要寫 `taxonomy chart atmosphere`，
寫 `taxonomy mood`。

### 條目本身就是帶字的東西時

有些條目（`advertisement`、`newspaper`、`menu`、`sign`）**本體就是印著字的物件**，
換掉道具就等於換掉題材。這種情形照下面的順序處理，**不要卡在這裡**：

1. 先試「使用它的場景」——`advertisement` → 路人被街邊某個發亮的大型展示吸引而駐足回頭；
   `menu` → 一桌人指著桌上的餐點討論。
2. 再試「它造成的結果」——`newspaper` → 清晨門口捲成筒狀的紙、讀完後攤在桌上的空白版面。
3. 兩者都不成立時，**直接用那個物件**，把它畫成遠景或側面、不要正對鏡頭。
   接受它可能出現亂碼字——那比畫出一張看不懂的圖好。

---

## 不要做

- 不要輸出任何風格詞、品質詞、觸發詞、否定敘述（見上方清單）。
- 不要輸出多行、說明、標題、Markdown 圍欄或引號。
- 不要在場景中要求畫面出現文字、標籤、字幕、書名或招牌文字。
- 不要照抄條目本身的字面——要畫的是它的**語義**，不是那幾個字。
